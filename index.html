📚 Nuestra institución

La Institución Educativa Luis Calixto Leiva busca brindar una formación integral a sus estudiantes, promoviendo el aprendizaje, la responsabilidad, el respeto y la convivencia.

A través de esta página web se busca organizar y presentar información de manera sencilla para que estudiantes, padres de familia, docentes y visitantes puedan encontrar fácilmente lo que necesitan.

💻 Sobre este proyecto

Esta página web hace parte de un proyecto académico realizado con el propósito de aplicar conocimientos relacionados con el diseño y desarrollo web.

El proyecto busca crear un espacio digital organizado, sencillo y útil para la comunidad educativa de la Institución Educativa Luis Calixto Leiva.
